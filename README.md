# Loan vs. Investment Calculator

Should you pay off a loan quickly, or take a longer loan with a smaller EMI and invest the difference?

Enter your loan amount, interest rate, two loan periods and the return you expect from investing. The calculator compares:

- **Plan A:** take the shorter loan.
- **Plan B:** take the longer loan and invest the EMI you save each month.

Both plans cost the same every month until the shorter loan ends. At that point Plan A is debt-free. Plan B has an investment pot but still owes part of the loan. The calculator shows which one leaves you better off, and by how much, across a range of returns.

Rule of thumb: Plan B only wins if your investments earn more than your loan's interest rate, after taxes and fees.

## Running locally

```bash
npm install
npm start      # dev server at http://localhost:3000
npm test       # run tests
npm run build  # production build in ./build
```

*This tool gives estimates, not financial advice.*
